## 2. Что работает хорошо — сохранить
- Быстрый путь к вопросу: «Играть» на главной, гость без регистрации, ~7 с от открытия до первого вопроса на локальном сервере (подставной SDK, без сети — на телефоне будет дольше).
- Подбор вопросов: невиденные вперёд, рост сложности, смешение тем. Менять структуру банка не нужно.
- Честная экономика: звёзды только на оформление, реклама в паузах, ролик за 50/50 добровольный.
- Вопрос дня с реальной статистикой — готовая основа для «Ловушки дня».
- Тестовая обвязка (`harness.py`, подставные SDK и база) — новые правила покрывать там же.

## 5. Что может сломать игру
- Любая смена порядка `BANK`: индексы используют `seen`, `games.qs`, квиз и вопрос дня. Править вопросы только на месте, не удалять.
- Изменение `dailyQ` меняет вопрос дня всем посреди дня — вводить с новой даты.
- Изменение `revealSec` для дуэлей и блица меняет условия соревнования — сейчас тронут только «Играть» (один игрок).
- Облачное сохранение `S`: новые поля только добавлять, `merge` должен их понимать.

## 6. Аналитика: чего не хватает
Есть счётчики дня (`day_stats`) и воронка партии. Нет: время до первого вопроса, просмотр пояснения, отказ от партии, когорты D1/D7/D30 по игрокам. Минимум: `qm("fq")` при первом показанном вопросе с временем от загрузки; `qm("exp")` при показе пояснения; когорты — запросом по `track_visit` (дата первого визита). Персональных данных не добавлять.
