# PLATFORM_MATRIX — платформы

Обновлено 12.11.2026. «Проверено» = код + локальная проверка (подставной SDK или обычный браузер). На реальной платформе ничего не проверялось.

## Что поддерживается сейчас
| Возможность | Яндекс Игры (этот репозиторий) | Обычный браузер (этот же код без SDK) | Основной сайт (отдельная копия) |
| --- | --- | --- | --- |
| Основной квиз, быстрые режимы, квиз дня | есть | есть, проверено | есть |
| Режимы для компании (вечер, массовый, команды) | в коде, скрыты CSS | скрыты тем же CSS | открыты |
| Личность игрока | анонимный Supabase + Яндекс ID для рейтинга/покупок | анонимный Supabase | e-mail в Supabase |
| Сохранение | localStorage + облако Яндекса (только быстрые режимы) | localStorage + Supabase (основной режим) | Supabase |
| Реклама | `ysdk.adv` | нет (пропускается) | нет |
| Покупки | `ysdk.payments` (starter, noads, founder) | нет (блок скрыт) | нет |
| Лидерборды | `ysdk.leaderboards` (`arcsurv`, `arcblitz`, `arctf`, `arcpic`, `arccls`) + внутренний рейтинг | только внутренний рейтинг | внутренний рейтинг |
| Вызов по ссылке | `yandex.ru/games/app/<id>?payload=d_<id>` | `#d=<id>` в адресе | своя ссылка |

## Как вводить вторую платформу (без большого рефакторинга)
Объект `YG` уже служит адаптером. При второй платформе:
- определить платформу один раз при старте (`window.YaGames` / `Telegram.WebApp` / иначе — веб);
- держать один объект `PLATFORM` с методами `ready`, `pause`, `showInterstitial`, `showRewarded`, `player`, `cloudSave/Load`, `payments`, `leaderboard`, `shareLink(payload)`, `launchPayload` — сейчас это функции `ygAdv`, `ygReward`, `getPl`, `cloudPush`, `payInit`, `lbApi`, `ygLink`;
- функции, которых у платформы нет, возвращают `null`, а интерфейс их прячет (как сейчас с покупками).
