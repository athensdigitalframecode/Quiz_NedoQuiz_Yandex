## Текущее состояние
Один файл `index.html` (HTML+CSS+чистый JS, без сборщика), банк `BANK` ~1,4 МБ. Платформы: Яндекс Игры (`ysdk`), GamePush (`gp-adapter.js`), работа без SDK (веб). База — Supabase, одна таблица `docs` (path, col, id, data jsonb, updated_at) с обёрткой в стиле Firestore (`sbDoc`/`sbCol`/`sbWatch`); правила — триггер `docs_guard`, рейтинг — RPC `stat_bump`, счётчики дня — RPC `track_day`. Автотесты: Playwright + подставные SDK и база (`dev/tests`, 162 проверки). В базе ~25 профилей — до коммерческого запуска.

## Критические проблемы
1. ~~**Трафик Supabase:** подписки перекачивали `profiles`/`teams`/`disputes`/`suggest`/`challenges` целиком каждые 8 с и при любом изменении~~ — этап 1, 25.11.
2. **Жалобы читают все клиенты** (§8.1, §12): приватность и трафик. Исправление требует серверного подсчёта — миграция с согласия владельца.
3. **`qstats`** — 2 запроса на вопрос и потеря счёта при одновременных партиях (§8.3). Миграция с согласия владельца.
4. **Нет обработки кнопки «Назад»** — блокер для Android-версии (§10.2).
5. Покупки, реклама, лидерборды, `payload` не проверены на платформе (R-04, владелец).
6. Слияние облачного сохранения возвращает потраченные звёзды (R-19).
