# ARCHITECTURE — как устроена игра сейчас

Обновлено 12.11.2026 по коду `main` (`1314909`) плюс локальные правки. Описывает то, что есть, а не идеал.

## Файлы
| Файл | Роль |
| --- | --- |
| `index.html` (~2,5 МБ, ~5 300 строк) | Вся игра: HTML, CSS, JS без сборщика. Банк `const BANK=[...]` — одна строка ~1,4 МБ |

## Слои внутри `index.html`
Номера строк меняются — искать по якорю (`grep -n`).

1. **Ядро основного режима** (глобальные функции): `TOPICS`, `BANK`, `pickQs`, `makeGame`, `renderGame`/`tickUI`, `saveStats`, `drawEnd0`, `RANKS`, `ACHS`. Партия — документ `games/<code>` в Supabase, «хост» (клиент) ведёт её сам. Это же касается дуэлей, вечера, массового квиза.
2. **Обёртка базы** `sbDoc`/`sbCol`/`sbWatch` — API в стиле Firestore поверх одной таблицы `docs(path, data)`; реалтайм через Supabase Realtime.
3. **Модуль быстрых режимов** (IIFE): `MODES_A`, состояние `S` (localStorage + облако Яндекса `player.setData({arc:S})`, слияние `merge` по максимуму), магазин за звёзды, покупки, лидерборды, серия `S.sk`, «Слово дня».
4. **Слой платформы Яндекс** — объект `YG` и функции рядом с ним:
   - инициализация `YaGames.init` (ждёт `window.YaGames` до 15 с), язык, `LoadingAPI.ready` после главной, `GameplayAPI.start/stop` по статусу вопроса;
   - пауза/звук `ygPause` по `game_api_pause/resume` и на время рекламы;
   - реклама `ygAdv` (полноэкранная, ≥90 с) и `ygReward`;
   - игрок `getPl`, облако `cloudPush`/`cloudFlush`;
   - покупки `payInit` → `procBuys` (при каждом запуске), `buyReal`;
   - лидерборды `lbApi` → `ysdk.leaderboards`;
   - ссылки `ygLink(payload)`, `gameUrl()`, чтение `environment.payload`.
5. **Аналитика**: `met()`/`QMET` → RPC `track_day` → `day_stats`.

## Поведение без SDK Яндекса (обычный браузер) — проверено 12.11
- Игра грузится, главная открывается, анонимный вход Supabase работает.
- Реклама пропускается (`ygAdv` сразу вызывает продолжение), покупки не инициализируются (`PAY=false`, блок товаров не рисуется).
- Рейтинг быстрых режимов показывает «Рейтинг доступен на Яндекс Играх».
- Ссылки вызова — `location.href` + `#d=<id>`.

То есть «платформенный адаптер» де-факто уже есть: всё платформенное идёт через `YG.sdk` и проверки его наличия. Отдельный рефакторинг в адаптеры сейчас не нужен; при добавлении второй платформы — вынести эти функции в объект `PLATFORM` с теми же именами (см. `PLATFORM_MATRIX.md`).
